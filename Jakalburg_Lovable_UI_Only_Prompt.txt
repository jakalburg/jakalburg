# 4. Typography

Use a clean modern sans-serif font.

Preferred public fonts:

- Inter
- Manrope
- DM Sans

Use Manrope as the main recommendation:

```css
--font-sans: "Manrope", "Helvetica Neue", Arial, sans-serif;
```

Typography direction:

- Strong editorial display headings
- Tight heading letter spacing
- Clean body text
- Compact product metadata
- Medium rather than extremely bold weights
- No decorative script fonts

Suggested hierarchy:

- Hero heading: 56–72px desktop, 38–48px mobile
- Page title: 44–56px desktop, 32–40px mobile
- Section heading: 32–42px desktop, 26–32px mobile
- Product title: 30–40px desktop, 26–32px mobile
- Product-card title: 14–17px
- Body: 15–17px
- Labels: 11–13px
- Buttons: 14–16px

Use:

```css
overflow-wrap: break-word;
word-break: normal;
```

Never use:

```css
word-break: break-all;
```
